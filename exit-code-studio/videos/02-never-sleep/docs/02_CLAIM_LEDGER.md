## Classes and how the narration may phrase them

| Class | Narration wording |
|---|---|
| **ESTABLISHED FACT** | stated plainly |
| **RESEARCH-SUPPORTED EVIDENCE** | "studies suggest", "in one study", "linked to", "in mice" — never "proves" |
| **HYPOTHETICAL ASSUMPTION** | "imagine", "in this world" — the rules of the thought experiment |
| **SPECULATIVE SCENARIO** | "might", "could", "would probably" — never a prediction |
| **UNKNOWN** | "nobody knows", "scientists still argue" |

## J · The rules of this world (HYPOTHETICAL ASSUMPTIONS)

| ID | Rule |
|---|---|
| HR1 | From one day onward, no human needs sleep — including babies born afterwards. The change is global and simultaneous. |
| HR2 | Sleep pressure never builds: nobody ever feels sleepy or exhausted from being awake. |
| HR3 | Whatever sleep does for brain and body — the known parts and the unknown parts — happens normally while awake. Not sleeping causes no harm. |
| HR4 | The circadian clock keeps running. Light still sets it, melatonin still rises at night, body temperature still dips before dawn — none of it makes anyone tired. |
| HR5 | People can still lie down, rest and close their eyes; they just never fall asleep. No sleep means no dreams. |
| HR6 | Everything else is unchanged: physics, the sun, the economy's starting point, human nature. |
| HR7 | **How** it happens is never explained. It is a thought experiment, not a mechanism. |
